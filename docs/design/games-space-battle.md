# משחק "קרב בחלל" (Space Battle) — איפיון מלא

> המשחק החינוכי הראשון בדף המשחקים של התלמיד. **משחק קרב אמיתי** (לא דף תרגול):
> דמות, אויב, פסי חיים, אנימציות אקשן, ניצחון/הפסד.
> עלות שחקיה: **200 כוכבים**. הקושי **מתאים לרמת התלמיד מהשאלון ההתחלתי** ומתעדכן חי.

---

## 1. הרעיון
קרב **מבוסס‑תורות** בין החללית של התלמיד 🚀 למפלצת חלל 👾. כל אחד עם **פס חיים (HP)**.
- עונה **נכון** → החללית תוקפת, המפלצת מאבדת HP.
- עונה **לא נכון** → המפלצת תוקפת, התלמיד מאבד HP.
- **רצף נכונות** → "מתקפת על" 💥 (נזק כפול).
- מנצח את המפלצת לפני שנגמרים החיים → **🎉 ניצחון**. נגמרו החיים → הפסד, אפשר שוב.

מבוסס‑תורות = **הוגן לכל גיל** (אין צורך ברפלקסים), אבל יש **מתח אמיתי** (אפשר להפסיד).

---

## 2. חיבור לרמת התלמיד (השאלון ההתחלתי) — הלב של ההתאמה

הרמה כבר קיימת במערכת — נתחבר אליה, לא נמציא מחדש:

```
שאלון התחלתי (LevelManagerPage / initial-assessment)
        │  קובע רמת פתיחה
        ▼
StudentProgress.currentLevel  (1–10, לכל תת-נושא)
   +  masteryLevel             (כללי, בדשבורד)
        │
        ├──────────────► תרגול אדפטיבי (קיים)
        └──────────────► 👾 קרב בחלל (חדש)  ← קורא את אותה רמה
```

**הרמה חיה:** ככל שהתלמיד עולה רמות בתרגול → המפלצות בקרב נעשות חזקות יותר אוטומטית. לא קופא על תוצאת השאלון.

### שילוב הבחירה + החולשה (האפשרות שאושרה: ב'+ג')
לפני הקרב, התלמיד **בוחר כוכב לתקוף** — וכל כוכב = תת‑נושא:

```
   בחר כוכב לקרב:

   🪐 חיבור        🔴 שברים ⚠️ מומלץ        🌕 כפל
   רמה שלך: 4      רמה שלך: 2  (חלש!)        רמה שלך: 5
   מפלצת: בינונית  מפלצת: קלה (מתאים לך)     מפלצת: חזקה
```

- **קושי המפלצת + השאלות = `currentLevel` של התלמיד בנושא שנבחר** (מהשאלון/התקדמות).
- **הכוכב החלש ביותר מסומן "⚠️ מומלץ"** (מהחולשות שכבר מחושבות בדשבורד) → המשחק מתרגל בדיוק את החולשה. כיף **וגם** ממוקד.

> מקור הנתונים כבר מוכן: הדשבורד מחזיר `topics` עם `currentLevel`+`successRate`, ו‑`recommendations`/`weakest`. נשתמש בהם.

## 5. מודל הקרב (HP / נזק / רצף)

| פרמטר | ערך מוצע (MVP) | מושפע מהרמה? |
|--------|----------------|--------------|
| חיי התלמיד | 5 ❤️ (5 טעויות = הפסד) | קבוע |
| חיי המפלצת | 8–14 (לפי רמה) | ✅ רמה גבוהה → מפלצת חזקה יותר |
| נזק תשובה נכונה | 1 | — |
| רצף 3+ נכונות | "מתקפת על" = נזק ×2 | — |
| נזק טעות (המפלצת) | 1 ❤️ | — |
| קושי השאלות | רמת התלמיד בנושא | ✅ מהשאלון/התקדמות |

→ ניצחון דורש ~8–14 תשובות נכונות (לפי הרמה); 5 טעויות → הפסד. **מתח אמיתי**.

## 6. ייצור השאלות (MVP)

**פיילוט = חשבון בסיסי** (כמו שהאיפיון ממליץ להתחיל). שתי אפשרויות:

- **MVP מהיר (מומלץ):** השרת מוריד 200 ומחזיר `{ topic, level, seed }`. הלקוח **מייצר את שאלות הקרב** ברמה הזו (חשבון בסיסי — חיבור/חיסור/כפל/חילוק לפי הרמה) ובודק תשובות מקומית. אין צורך ב‑microservice לפיילוט.
- **הקשחה עתידית:** endpoint `/games/question` שמנצל את מחולל השאלות הקיים לכל נושא, עם בדיקת תשובה בשרת.

> **הפרדה מהתרגול:** תשובות במשחק **לא** משנות את ההתקדמות/רמות/כוכבים האמיתיים (התלמיד כבר שילם 200 כדי לשחק). המשחק קורא את הרמה אבל לא כותב אליה — כך הוא "משחק", לא דלת אחורית לעלות רמות.

## 7. מנגנון 200 הכוכבים (מאובטח בשרת — כמו חנות האווטארים)

```
POST /games/play   body { gameKey: "space-battle" }
  ├─ totalStars < 200 → 402 { error:"INSUFFICIENT_STARS", needed:200, have:X }
  └─ totalStars ≥ 200 → totalStars -= 200; save → 200 { gameId, seed, newStarBalance }
```
ניכוי תמיד בשרת (אותו דפוס מוכח מ‑`selectAvatar`). יציאה/הפסד באמצע → הכוכבים כבר שולמו (כרטיס כניסה).

---

## 8. תגמול בסיום
- **ברירת מחדל:** net‑negative (משלם 200, לא מקבל כוכבים בחזרה) → כוכבים נשארים משמעותיים.
- **ניצחון** → 🏆 באדג' "מנצח החלל" + קונפטי + חיזוק. *(להחליט: בונוס כוכבים קטן על ניצחון מושלם? המלצה: לא ל-MVP.)*

## 11. יושרות קצה
- אין מספיק כוכבים → התראה + "לתרגול", בלי ניכוי.
- רענון באמצע קרב → לשחזר מ‑localStorage (seed+מצב) כדי לא לאבד שחקיה ששולמה.
- לתלמיד אין עדיין רמה בנושא (לא תרגל) → ברירת מחדל רמה 1 / masteryLevel.

## 12. שאלות פתוחות (לפני מימוש)
1. **גיל/נושא פיילוט ראשון?** המלצה: חשבון בסיסי (חיבור/חיסור) — הכי פשוט לייצר בלקוח.
2. **חיי התלמיד:** 5 ❤️? (כמה טעויות מותרות עד הפסד).
3. **בונוס כוכבים על ניצחון?** המלצה: לא ל‑MVP (רק באדג').
4. **בחירת כוכב חובה, או "קרב מהיר" ברמה הכללית?** המלצה: בחירה, עם הכוכב החלש מסומן מומלץ.
